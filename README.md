# WikiJumper

WikiJumper is a small, browser-based Wikipedia link game. Start on a random
Wikipedia article, then enter the title of another article linked from the
current page. Each valid link advances the journey and earns a point; an
incorrect guess ends the game. Starting a new journey picks another random
article.

## Run it

Open `index.html` in a browser, or serve this folder with any static web server.
The game uses the Wikipedia API and needs an internet connection.
